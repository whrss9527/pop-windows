# Windows 体验优化清单

每轮完成后运行核心测试、编译和 Windows 界面与手势回归，再进入下一轮。

0.11.0 已实现下列三个 P0 项；核心测试和本机编译通过，Windows 界面回归随合并请求运行。

| 优先级 | 问题或想法 | 验收标准 |
| --- | --- | --- |
| P0 | 设置保存失败没有界面反馈 | 设置窗口底部持续显示真实保存状态，可重试；错误不因翻页消失 |
| P0 | 复制失败仍显示成功或关闭卡片 | 按钮、结果行和 Enter 都按实际写入结果反馈，失败保留内容并允许重试 |
| P0 | 设置临时文件容易相互覆盖或遗留 | 每次写入使用独立临时文件，失败不替换原文件并清理临时内容 |
| P1 | 设置页较多，功能不易找到 | 增加按用途搜索设置的入口，支持关键词和键盘导航 |
| P1 | 剪贴板历史混合类型难找 | 按文字、图片、文件和固定内容筛选，筛选状态清楚可恢复 |
| P1 | 设置导入预览不够具体 | 导入前显示主要变化与数量，继续保留自动备份与失败回滚 |
| P1 | 连续修改设置频繁写入 | 合并短时间内的写入，退出前保存最新内容，并准确显示待保存和失败状态 |
| P2 | 首次使用缺少明确引导 | 能快速了解唤起方式、排除应用与常用工具，提供可恢复默认的操作 |
| P2 | 搜索结果缺少可发现的常用项 | 支持用户固定常用工具，避免改变既有圆盘布局 |
