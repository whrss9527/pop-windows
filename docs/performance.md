# 性能检查

优化覆盖重复图像处理、功能适用性解析、列表重建和剪贴板预览；截图、原文与粘贴内容保持完整。

- 取色、框选与标尺：GDI 位图直接复制为冻结的 BGRA 位图，不再为预览执行整屏 PNG 编码和解码。快照与原位图独立，可在原位图修改或释放后使用；覆盖半透明像素和反向扫描线。
- 取色和标尺在预览建立后立即释放原始 GDI 位图，不再一直持有到操作结束；4K 屏幕的该位图像素区为约 31.6 MiB。标尺确认只返回物理坐标，不裁剪、不编码用不到的 PNG。
- 全部功能搜索：每次打开列表创建适用性缓存，同一功能、同一选区只解析一次；启用状态仍逐次筛选，新选区和重新载入的插件重新判断。边缘「更多」只检查自己的功能。
- 列表方向键：保留未改变的行，仅更新原选中行和新选中行。功能、剪贴板和短语列表共用这条路径，避免反复重建图片及控件。
- 剪贴板长文本预览：只构造所需前缀，保持换行、制表符和空白的原有显示规则，按完整文字元素截断；长尾空白需要扫描，但不再分配整段预览字符串。原文仍完整保留。
- 剪贴板缩略图：在后台解码，同一路径合并请求；最多两张并行，按最近使用保留最多 256 张，最长边 96 像素。256 张 96 × 96 图片按 32 位像素计算为 9 MiB，实际占用还受像素格式、解码器与控件影响。缺失或损坏图片回退图标，同一会话不反复读取；隐藏后取消队列、清空缓存，再次打开重试。
- 隐藏功能、剪贴板和短语浮窗时拆开旧视觉树，释放文本、图片与毛玻璃快照，再次打开重新构建；缩略图任务用会话编号阻止旧结果回填。
- 多文件历史只扫描一次计数，仅分配前三条原始路径；预览截到 120 字符内的完整文字元素，实际粘贴仍使用全部原始文件路径。
- 短语搜索分别检查正文和标题，保留跨标题/换行/正文的匹配规则，不再拼接完整正文；自动标题只读取首行，正文预览限制为 160 字符并保留换行标记，模板展开与粘贴仍使用完整正文。
- 可选行索引只在搜索结果变化时更新；方向键与 Ctrl+数字复用索引，跳过分组和禁用项，不再逐键扫描和分配整组可选项。

## 自动验证

核心测试覆盖缓存调用次数、新选区和同 ID 插件重新载入的失效行为，以及查询顺序、功能开关的一致性。

Windows CI 在浅色、深色演示中执行 `PerformanceChecks`：

1. 逐字节核对直接转换与 PNG 路径的像素；验证快照不依赖原位图及反向扫描线方向。
2. 对固定的 1920 × 1080、3840 × 2160 像素输入，预热后各运行三次，记录耗时与托管分配中位数。
3. 创建含分组及禁用项的 100 行列表，验证选择跳过禁用项、反向移动和环绕，三次移动只新增六行控件。
4. 继续执行真实取色、自动/手动标尺、列表键盘选择、选择工具条和剪贴板恢复交互。
5. 对 180 万字符的固定文本记录整段拆分与前缀预览的耗时和托管分配，核心测试验证普通预览一致、emoji 边界和分配不随原文长度增长。
6. 实际解码横向和纵向长图，验证 96 像素上限、冻结、文件句柄释放、会话重开刷新、缺失与损坏文件、缓存淘汰，以及两个后台解码期间清空队列的取消行为。
7. 隐藏并重开真实 WPF 列表，检查旧视觉树和选择已清空，新列表仍可正常使用。
8. 以 10,000 条文件路径和 90,000 字符短语为固定输入，比较文件摘要、短语搜索和预览的托管分配；核心测试对照原搜索规则、路径顺序与数量，验证只改变预览、不改动粘贴内容。
9. 在真实列表中搜索，验证禁用首项、过滤后环绕、Ctrl+数字直选、极大步长和无结果时的选择行为；`list-content=ok` 与 `list-selection=ok` 为必需标记。

结果在截图分支 `ci-screenshots/windows-2022`、`ci-screenshots/windows-2025` 的 `ui/light-demo.txt` 和 `ui/dark-demo.txt` 中。先核对分支 README 中的提交号，再查看 `screen-snapshot=ok`、`list-navigation=ok`、`text-preview=ok`、`clipboard-thumbnails=ok`、`overlay-release=ok` 和 `performance:` 行。

`png-ms`、`direct-ms` 仅比较相同输入的图像转换，不代表完整工具启动时间；`managed-bytes` 不含 WPF/WIC 的原生内存，不能作为进程总内存。CI 不对耗时设置硬阈值，以免共享运行器负载波动产生误报。

## 在 Windows 单独运行

```powershell
$env:POP_SMOKE_MARKER = Join-Path $PWD 'performance.txt'
Start-Process .\Pop.exe -ArgumentList '--demo-shots', 'performance-shots', '--demo-scenes', 'performance' -Wait
Get-Content $env:POP_SMOKE_MARKER
Remove-Item Env:POP_SMOKE_MARKER
```
